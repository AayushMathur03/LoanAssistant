# Required Evidence and Supporting Documents Policy v1.0

## Section 1.0 Purpose
### 1.1 Objective
This synthetic policy defines mandatory evidence categories.

## Section 2.0 Identity Evidence
### 2.1 Acceptable Types
Synthetic Passport or synthetic Driver License.

## Section 3.0 Income Evidence
### 3.1 Primary Evidence
Synthetic recent paystub and synthetic bank statement.
### 3.2 Additional Evidence
Additional income evidence follows the Income and Employment Verification Policy.

## Section 4.0 Mortgage Evidence
### 4.1 Property Appraisal
Property appraisal is mandatory for mortgage scenarios where property valuation is required.

## Section 5.0 Missing Evidence
### 5.1 Pending Information
Missing mandatory evidence keeps recommendation status as `Pending Information`.
### 5.2 No Model Invention
The model cannot invent a missing document, field, value, or verification result.

## Section 6.0 File Intake Controls
### 6.1 Validation
Validate supported file type and size before extraction.
### 6.2 Suspicious Files
Unsupported or suspicious files must be rejected safely.

## Section 7.0 Provenance
### 7.1 Field-Level Provenance
Extracted fields retain source document and location metadata.
### 7.2 Confirmation
Low-confidence fields require applicant or officer confirmation.
