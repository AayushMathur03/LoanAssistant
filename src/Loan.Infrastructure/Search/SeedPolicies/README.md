# Synthetic RAG Policy Corpus

8 strictly synthetic, versioned banking policy/product documents for the Loan Application & Compliance Review Assistant capstone.

All values are fictional and for demonstration/testing only. Do not treat these as actual bank policy or legal advice.

Each document includes YAML frontmatter for DocumentId, Title, ProductId, PolicyVersion, DocumentType, Audience, EffectiveFrom and EffectiveTo, plus structured markdown headings for RAG chunking and citations.
